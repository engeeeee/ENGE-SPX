# 容器语言与出口地区

从 **0.15.2** 起，在 **偏好设置 → 环境设置 → 容器语言** 选择：

| 模式 | 作用 |
| --- | --- |
| 保持现有语言 | 默认兼容旧配置，不主动查询语言地区；启用过此功能后选择它，会在下次启动恢复基础环境的英文 UTF-8 |
| 跟随第一跳线路出口 | 使用独立核验的 `line_ip`；需要启用前置线路，本机 v2ray 与软件内双跳均可 |
| 跟随最终落地出口 | 使用双来源核验的最终 `ip`，与目标服务看到的出口对应 |

保存设置，停止已有工作后重新检查，在出口确认框核对语言，再打开新的 CLI／浏览器。第一跳与最终落地可能在不同地区，软件不会悄悄混用。时区维持原有模式；希望语言和时区都对应网站看到的出口时，应选择最终落地来源。

## 中文输入与语言环境分别处理

- Windows 系统、软件界面和中文输入法保持原设置。终端继续显示和输入 Unicode／中文，不需要安装中文字体到容器。
- CLI 使用所选 `LANG`、`LC_CTYPE` 和真实 glibc UTF-8 数据；`LC_MESSAGES=C`、`LANGUAGE=en` 保留常规英文诊断，清空旧镜像的 `LC_ALL` 覆盖。模型回复语言仍由提示词和会话决定，不写入或修改用户的 CLAUDE.md／AGENTS.md。
- `/etc/default/locale` 与应用新启动 CLI 的环境相符。已有 Docker 容器创建时的默认环境无法原地更改；在应用外直接运行不带参数的 `docker exec` 可能仍显示旧默认值。网络诊断对项目工作区按实际应用启动环境采集。
- Chromium 使用所选 UTF-8 locale 和标准 `ForcedLanguages` 策略，影响首选语言、`navigator.language(s)` 和请求语言。没有注入 JavaScript 指纹覆盖、改 User-Agent 或伪造检测结果。

## 安全与运行开销

仅在主动检查且启用此功能时，经过既有受控代理查询已核验的明确 IP。请求保留 HTTPS 证书验证，不使用 Windows DNS 直接查询节点，不回退直连；缺少第一跳、未知／不支持地区、查询失败时要求重试或保持原语言，不静默套用美国设置。确认时验证语言来源 IP 未变。

目前提供常用地区的默认 locale，包括美、英、日、韩、德、法、荷、加、澳、新、新加坡、港、台等。多语言国家采用一个地区默认值，并不能由 IP 推断某个人的首选语言。地区、时区、语言与其它环境信息仍可能不一致；此功能不保证避开网站检测。

使用基础镜像中已有的 locales 源数据，不下载依赖或字体。项目容器以原用户在自己的临时目录编译并缓存 locale，通过固定公开配置文件同步系统默认值。只读浏览器在无网络、无用户数据挂载的临时准备容器里生成可复用镜像；实际浏览器继续为 UID1000、只读、丢弃全部 capabilities 与原 seccomp／Chromium 沙箱。第一次生成有一次性 CPU、磁盘开销；后续同语言复用，不增加后台轮询。

项目容器、可写层、目录授权、账号卷与浏览器 Profile 保留。切换语言要重新确认连接，不热改正在输入的会话。关闭后可回到原英文 UTF-8 环境。

新浏览器在收到启动授权前，先核验该 Profile 卷只被当前容器使用，且容器内没有 Chromium 进程，然后只清理固定的 SingletonLock／SingletonSocket／SingletonCookie 符号链接。存在其他使用者、状态不可核验、目录链接或异常普通文件时拒绝处理；不跟随链接、不删除账号或其它 Profile 文件。此机制处理旧容器主机名残留锁，沙箱和持久数据验证仍保留。

## 线路选择修复

连接页分别标明第一跳与最终落地。第一跳只列加密能力符合条件的节点；HTTPS 可用于加密第一跳，普通 SOCKS5/HTTP 只能在此链路中用作落地。落地仍兼容已有的其它受支持协议。新选第一跳不继承旧服务器 IPv4 与出口锁定；当前 UI 会话中为各线路分别保留填写值，不自动通过宿主 DNS 填充域名地址。应用重新打开后恢复已保存的当前线路；其它未保存的填写值不会自动持久化。

技术依据：[Chromium 语言偏好定义](https://chromium.googlesource.com/chromium/src/+/HEAD/components/language/core/browser/pref_names.h)、[Chrome ForcedLanguages 策略](https://chromeenterprise.google/policies/?policy=ForcedLanguages)。真实 UTF-8、浏览器请求语言和沙箱验证脚本为 `tests/integration_workspace_language.py`；它使用无外网测试容器，不使用真实账号。
