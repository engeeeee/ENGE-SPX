- 修复 Antigravity CLI（AGY）调整窗口大小时先跳到会话开头、再回到最新一行的显示问题。连续尺寸变化会合并，重绘稳定后再刷新画面。
- 从工作台打开的 SSH 与容器智能终端集中在会话侧栏。点击标题栏左侧按钮可收起或展开列表。
- 在「快捷输入」和「SFTP 文件」旁点击「独立窗口」可单独查看当前会话，也可移回侧栏。连接、历史与草稿随原会话保留。
