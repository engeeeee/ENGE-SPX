**ENGE SPX 0.15.16**

- SSH 和 Linux Shell 的输入区会显示常用指令的灰色后缀。输入 `git st`，按 Tab 填入 `git status --short`，随后由你按 Enter 执行。也支持自己保存的快捷指令。
- SSH 页面增加「SFTP 文件」和「临时 SFTP」。已打开的 SSH 终端也可以从顶部进入该服务器的文件管理窗口。
- SFTP 支持浏览路径、上传多个文件、下载文件、新建文件夹和取消传输。同名文件保留，完成后才生成最终下载文件。
