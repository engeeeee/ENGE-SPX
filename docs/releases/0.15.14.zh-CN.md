**ENGE SPX 0.15.14**

- 修复部分 Windows 环境下，SSH 终端只能看到最近一屏 Codex 对话的问题。行内模式可在滚动记录中查看早期输出，全屏模式支持滚轮翻阅。
- 智能终端顶部新增「快捷输入」。也可以用 Ctrl+Shift+P 打开，按 Tab 或 Enter 将常用指令填入当前输入区，发送由用户确认。
- 新建或编辑 SSH 机器时可填写密码或私钥口令，使用当前 Windows 用户加密保存。
- 双击保存的机器或点击「连接」直接打开终端。首次连接仍需核对主机指纹，未保存凭据时可在终端输入。

安装版和便携版可直接升级，已经导入的 Docker 运行环境可继续使用。
