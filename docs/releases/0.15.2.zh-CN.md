**ENGE SPX 0.15.2 · 线路选择修复与容器语言设置**

- 明确区分 **前置线路 · 第一跳** 与 **落地代理 · 最终出口**。普通 SOCKS5/HTTP 不再列入加密第一跳，本机 v2ray 模式禁用软件内第一跳选择。
- 切换软件内线路时同步当前服务器 IPv4 和出口锁定值，不再沿用上一个节点的地址与出口；同次运行中切回旧线路可恢复它自己的填写值。落地保持独立，无需为了刷新配置重复切换节点。
- **偏好设置 → 环境设置 → 容器语言** 可选择跟随第一跳线路出口或最终落地出口。旧配置默认保持现有语言；主动启用后重新检查并核对出口。
- 采用标准 UTF-8 locale 与 Chromium 首选语言。Windows、软件界面和终端中文输入不改变；CLI 常规诊断仍为原来的英文，AI 回复语言由你的提示词与会话决定。
- 项目层、工具账号与浏览器 Profile 保留，不安装字体或额外依赖，不扩大挂载、容器权限或开放直连。已有基础镜像无需重新准备；首次选用一个语言时离线生成它的 locale，之后复用。

语言来源按明确选择的出口 IP 查询。第一跳和最终落地可能在不同地区，时区仍沿用原有“跟随落地出口／手动固定”选择。地区默认语言不代表个人偏好，也不保证规避网站检测。详见[语言设置与边界](../workspace-language.zh-CN.md)。

在软件内检查更新后下载并重启，或使用本页安装版／便携版。升级后重新检查并确认出口；不需要清空配置或删除项目环境。
