- 调整智能终端窗口大小时保留 AGY 当前的视口和草稿，等历史重绘完成再刷新。覆盖工作台直接启动、SSH 和 Linux Shell 中运行的 AGY。
- SSH 因网络故障断开后在原标签页自动重试，并保留滚动历史。连接表单已填写或保存的凭据可用于重新认证，继续核验服务器指纹。原连接已经失效时，重连会进入新的远端 Shell。
