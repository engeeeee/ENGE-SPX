# ENGE SPX 0.15.9

- 重新准备时会重新核验已经失效的工作区。使用旧续期文件的网关会切换到追加续期，过期的出口核对会引导回连接检查。
- 本机线路中转会等待已有进程释放锁。遇到短暂的 Windows 文件共享冲突，网关撤销和中转心跳会重试。
- 智能终端会重试短暂占用的文件，并提示具体的权限、占用或路径问题。修复同步帧后的输出漏绘及连接结束时的 UTF-8 解码。
- 未设置资源偏好时，普通 CLI 按需打开 Chromium，减少浏览器常驻占用。显式登录会打开工作区浏览器，也可以在「资源 → 预算设置」启用「随工具启动浏览器」。
- 普通终端输出减少了重复的控制序列扫描和附件标记检查。宿主子终端启动时会清理继承的浏览器令牌。
