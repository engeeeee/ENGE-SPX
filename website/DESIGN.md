# ENGE SPX 官网设计

沿用 0.16.2 桌面工作台与智能终端的视觉规范：夜间模式以纯黑画布（`#000000`）和黑曜石边框（`#1E1E22`）为基底，只在核心按钮与选中状态使用深蓝点缀（`#1D4B9E` / `#264B8F`）；白天模式采用纯白画布（`#FFFFFF`）、葱绿色选中状态与链接（`#237E49` / `#E9F6EE`）搭配 Claude 橙主按钮（`#D97757` 配纯白文字）。右上角可切换主题并保存偏好。颜色、间距与排版变量集中在 `src/app/globals.css`。

首页采用“价值摘要 + 5 视图交互预览台”分栏结构（工作台 / 项目工作区 / 远程 SSH / 连接与代理 / 智能终端），紧接四项核心能力概览卡片、项目工作区与身份隔离、双跳网络路径交互图、全宽智能终端展示区、独立的远程 SSH 与 SFTP 三模块交互区、资源预算与存储迁移、下载与校验面板，以及覆盖兼容边界与 DPAPI/SFTP 细节的 FAQ。所有产品信息与截图清单集中在 `src/lib/content.ts`。

工作台、项目、连接与资源截图来自 0.16.2 Windows 3× 实机采集；Codex 智能终端来自 0.16.2 Linux 实机采集；分组与 SSH 智能终端使用 0.16.5 真实 Qt 多会话界面渲染，远程 SSH 管理页与 SFTP 文件管理器使用 0.16.2 真实 Qt 界面及 RFC 5737 示例服务器信息以 2× 渲染并明确标注。点击任意截图可进入全尺寸阅读灯箱并放大浏览。
