# ENGE SPX 官网设计

沿用 0.16.2 工作台的配色。夜间模式用纯黑背景和深蓝按钮，白天模式用白色背景、绿色选中态和橙色操作按钮。右上角可切换并记住选择。颜色、间距和字号集中在 `src/app/globals.css`。

首页左侧介绍产品和下载方式，右侧可切换三张实机图。项目和资源分区使用图文分栏，代理网络图与终端使用完整内容宽度。安装步骤、包体积和校验入口放在下载区。通过 `src/lib/content.ts` 更新版本、下载及截图来源。

工作台、代理、项目与资源截图来自 Windows 上运行的 0.16.2，终端来自 Linux 上运行的 0.16.2 与 Codex 0.169.0。截图随主题切换，点击可打开完整原图并放大阅读。页面对部分图片只裁切窗口底部，保留实际软件内容。[截图采集记录](../docs/screenshots/README.md#工作台-0162)

代理图标明第一跳与落地出口。SOCKS5、HTTP、HTTPS 是落地协议的可选项。本机 v2ray 模式的按目标分流由外部客户端控制。
